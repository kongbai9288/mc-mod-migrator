隐私说明（模组迁移助手）

最后更新：2026-09-20

一、数据去向
本应用没有开发者服务器，也不会向你以外的任何人上传数据。
所有数据默认只留在你的手机上。真正发生上传的唯一场景，是你在「同步」页主动点击上传，
把配置包写入你自己在设置里填写的 GitHub 私有仓库。

二、本机存储的内容
1. GitHub Personal Access Token：使用 AndroidX Security 的 EncryptedSharedPreferences
   （AES-256 加密）保存在应用私有目录，不会写入日志，不会随备份明文导出。
2. 仓库所有者 / 仓库名 / 分支 / CurseForge API Key：同上，加密保存。
3. 你通过系统文件选择器授权的目录 URI：保存的是授权标识（URI），不是文件内容。
4. 你手动标记的下载链接：保存在应用私有目录的 marked_links.json。

三、会发起的网络请求
1. api.modrinth.com —— 搜索模组、查询版本、按文件哈希识别模组。
2. api.curseforge.com —— 仅当你填写了自己的 CurseForge API Key 时才会调用。
3. api.github.com —— 仅用于读写你自己的私有仓库（上传清单/配置包、拉取设备列表）。
4. 你手动标记的下载地址、以及你在「模组页面」里打开的网页 —— 由你决定访问哪个站点，
   本应用不代为收集这些站点返回的任何信息。

四、权限用途
- INTERNET / ACCESS_NETWORK_STATE：联网搜索与下载，判断网络可用性。
- POST_NOTIFICATIONS：显示下载与同步进度通知，可拒绝，不影响主要功能。
- 存储访问权限：仅用于读写你主动选择的游戏实例目录（Android 存储访问框架）。
  「所有文件访问」为可选项，默认不申请，只有你主动开启后才会使用。

五、你的控制权
- 设置页可随时清空本机标记与缓存。
- 卸载应用会删除全部本机数据。
- 可随时到 GitHub Settings → Developer settings → Personal access tokens 撤销 Token。

六、第三方组件
本应用使用了第三方开源库与第三方图标，许可见「第三方开源许可」页面。
这些组件各自可能发起其自身的网络请求（均为上述 API）。

七、变更
本说明如有更新，会随应用内该页面与仓库中的 PRIVACY.md 同步更新。
