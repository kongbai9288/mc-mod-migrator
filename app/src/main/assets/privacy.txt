ModMigrator 隐私说明

最后更新：2026-09-24（对应版本 1.2.0）

一、总原则

本应用是离线优先的工具。能在本机完成的事，绝不上网。
所有联网功能（搜索模组、检查更新、服务器面板、GitHub 同步）
都必须由你主动触发，或在设置里明确开启后才会执行。

二、我们不收集什么

- 不收集你的设备信息、通讯录、位置、短信、通话记录
- 不收集你的游戏账号、正版登录凭据
- 不上传你的存档、模组、配置文件到我们的服务器
- 没有内置任何统计分析、行为埋点、广告 SDK
- 代码里不含任何开发者自己的密钥或令牌

三、我们存储什么（都在你自己的设备上）

以下内容保存在本应用的私有目录，或你自己在「设置 → 存储」里
指定的工作目录，只有本应用能访问：

- 你填写的 GitHub Token、CurseForge Key、服务器面板凭据
  （用 EncryptedSharedPreferences 以 AES-256 加密存储）
- 模组收藏列表、迁移记录、日志
- 下载的模组与导出的迁移包

卸载应用会删除私有目录里的内容；工作目录里的内容不受影响。

四、联网说明

应用在以下情形会联网，且每次都可以在设置里关闭：

1. 搜索/下载模组
   Modrinth（api.modrinth.com）
   CurseForge（官方 api.curseforge.com，或国内镜像 mcimirror.top）
   ModMarket 后端（可在设置里改地址，默认 modmarket.3566500461.workers.dev）
   请求内容：你输入的关键词、MC 版本、加载器类型。

2. 检查应用更新
   向你自己在设置里指定的 GitHub 仓库读取 release 信息。
   不填仓库时，默认读本应用自己的公开仓库。

3. 服务器面板
   向你填写的面板地址查询服务器与文件列表。
   凭据只发给你自己填的那个地址，不会转发给任何第三方。

4. GitHub 同步
   用 OAuth 在浏览器里登录，应用拿到的只是访问令牌，
   不接触也不保存你的 GitHub 密码。
   上传到你指定的仓库（可设为私有仓库）。

5. 翻译
   翻译用 Google ML Kit 的离线模型。首次使用需要联网下载一次模型
   （约 30MB，由 Google 分发），此后翻译完全在你手机上完成，
   待翻译的文本不会发送给任何服务器。
   模型未下载时会走在线翻译接口兜底，此时简介文本会发送给该服务；
   开启「离线模式」可完全禁止。

6. 公告与版本检查
   向你自己在设置里指定的 GitHub 仓库读取 announcement.json 与
   release 信息。为提升国内可达性，会依次尝试若干第三方公开镜像
   （jsdelivr、gh-proxy 等），请求内容仅为仓库地址与文件名。

   **关于第三方镜像的特别提示**：这些镜像是社区公益代理，不是 GitHub
   官方服务，域名可能随时调整或下线，其运营方理论上能观测到你的访问。
   因此本应用**绝不会**把你填写的 Token、API Key 或任何凭据通过镜像发送
   ——带凭据的请求只走 GitHub 官方域名。如你不放心，可在设置中关闭镜像、
   只使用官方地址（代价是国内可能连不上）。

7. 站点内容抓取（周报）
   读取 MC百科、中文 Minecraft Wiki、Modrinth、红石计划等站点的
   公开页面，仅提取条目标题与链接用于展示，并标明来源站点。
   这些站点会看到你的 IP 与常规访问记录，适用其各自的隐私政策。

8. CurseForge 下载等待
   CurseForge 的下载页存在读秒跳转。为拿到真实下载地址，
   应用会在**后台**打开该页面等待跳转，页面不显示给你，
   等待结束或超时（45 秒）后立即销毁。此过程只与 CurseForge
   （或其镜像）通信。

五、流量与存储

- 移动网络下会累计已用流量，超过你设定的阈值时提醒一次（默认 200MB），
  该计数只存在本机，不上传。
- 删除的模组先放入回收站（工作目录下 trash/），
  按你设定的天数（默认 7 天）自动清理，期间可随时还原。
- 崩溃日志只写在本机，需你主动选择「分享」才会离开设备。

六、权限说明

- 存储访问：用系统文件选择器授权，只对你选中的目录生效，
  授权可随时在系统设置里撤销。不会申请整机存储权限。
  （安卓 11+ 上，若要读取 Android/data 下的启动器数据，
   需要你手动授予「所有文件访问」，应用会在必要时说明原因再引导你去开）
- 通知：用于显示下载进度与完成提醒，可在设置里关闭。
- 网络：仅用于上述联网功能，开启「离线模式」后不再发起请求。

七、第三方服务

本应用会向你自己在设置里填写的第三方服务发起请求
（Modrinth、CurseForge、你的服务器面板、你的 GitHub 仓库、
ModMarket 后端）。这些服务各自有自己的隐私政策，
你填写它们的凭据即表示你了解并接受其条款。
我们无法控制这些第三方如何处理你的数据。

八、你的控制权

- 设置 → 存储：随时更换或撤销工作目录
- 设置 → 关于 → 授权状态：查看当前授权了哪些目录，可清理失效授权
- 设置 → 离线模式：一键断网，所有联网功能停摆
- 设置 → 后端：清空 Token、退出 GitHub 登录
- 卸载应用：彻底删除本应用私有目录里的全部数据

九、未成年人

若你是未成年人，请在监护人陪同下阅读本说明后再使用。

十、变更

本说明如有更新，会在应用内「设置 → 关于」提示。
继续使用即视为接受更新后的说明。
