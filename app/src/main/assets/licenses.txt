一、运行库依赖（随应用一起分发）
============================================================

1. AndroidX（core-ktx / appcompat / recyclerview / documentfile /
   swiperefreshlayout / lifecycle / security-crypto / preference）
   许可：Apache License 2.0
   来源：https://developer.android.com/jetpack/androidx

2. Work Manager（androidx.work）
   许可：Apache License 2.0
   用于：后台定时检查更新、定时同步

3. Material Components for Android
   许可：Apache License 2.0
   来源：https://github.com/material-components/material-components-android
   用于：界面控件、主题、对话框、底部导航

4. OkHttp
   许可：Apache License 2.0
   来源：https://github.com/square/okhttp
   用于：所有网络请求。本应用的多线程分块下载器基于它实现。

5. Gson
   许可：Apache License 2.0
   来源：https://github.com/google/gson
   用于：JSON 解析

6. Jsoup
   许可：MIT License
   来源：https://github.com/jhy/jsoup
   用于：解析模组叙述页面，提取下载链接

7. Coil
   许可：Apache License 2.0
   来源：https://github.com/coil-kt/coil
   用于：加载模组图标

8. Material Icons（本应用所有图标）
   许可：Apache License 2.0
   来源：https://fonts.google.com/icons
   说明：全部为官方 Material Symbols，未使用任何第三方美术资源。

============================================================
二、参考的开源实现（思路参考，代码为本应用自行编写）
============================================================

以下项目的实现思路被参考，用于改进本应用的下载与目录扫描：

9. lingochamp / FileDownloader
   许可：Apache License 2.0
   来源：https://github.com/lingochamp/FileDownloader
   参考点：多任务并发、断点续传、分块下载的调度思路。
   说明：本应用未直接引入该库（它依赖较旧且体积较大），
        而是按同样的思路用 OkHttp 自行实现，因此不适用其许可约束，
        此处仍予致谢并标明来源。

10. jackfengji / android-download-manager
    许可：MIT License
    来源：https://github.com/jackfengji/android-download-manager
    参考点：HTTP Range 分块下载、并发任务数控制。
    说明：同上，仅参考思路。

11. SirLYC / YC-Downloader
    许可：MIT License
    来源：https://github.com/SirLYC/YC-Downloader
    参考点：多任务队列、速度限制、进度回调节流。
