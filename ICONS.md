# 界面图标 / Icon set

界面图标来自 **Tabler Icons**（MIT，https://tabler.io/icons），outline 风格。
内置在 `app/src/main/res/drawable/`，资源名规则：Tabler 原名把短横线换成下划线，再加 `ti_` 前缀。

例：Tabler 名 `cloud-down` → `@drawable/ti_cloud_down`。

新功能加图标时：先在下表里找 Tabler 原名，确认后按规则写资源名；
表里没有的，去 https://tabler.io/icons 找，再补进本目录并追加到下表。

共 489 个。
