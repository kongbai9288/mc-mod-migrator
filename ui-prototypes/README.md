# UI 原型库（UI Prototypes）

存放各页面的 **1:1 可交互 HTML 原型**（360×800，Material 3）。

**目的**：Compose 迁移后 UI 质量不达标，改为「先出原型 → 自评打分 → 达标再落地 Kotlin」的流程。原型存在仓库里，避免长对话被清除后丢失进度。

---

## 工作流程（每轮必须遵守）

1. 选一个页面，做 1:1 HTML 原型
2. **严格按用户逻辑自评 1–10 分**
3. **低于 8 分不许交付，改到达标为止**
4. 达标后用户真机/浏览器验收
5. 全部页面达标后，再一次性迁移到 Kotlin

**不要整页重写代码。** 一轮只做一件事、只动一个页面。

---

## 评分维度（每项 1–10，取综合）

| 维度 | 看什么 |
|---|---|
| 一眼能懂 | 层级清楚、不用点进去就知道状态 |

## 已确立的设计规则（务必保持，别再退回去）

1. **弹窗不是杂物抽屉**
   弹窗里只放同类内容。不相干的操作（分享、打开原文、标记链接、推荐）必须各归其位：
   - 属于列表操作 → 放列表项的按钮或「更多」菜单
   - 需要展示结果/图片/多个按钮 → **另开新页面**，不要塞弹窗
   - 属于筛选的 → 才留在筛选弹窗

2. **禁止隐藏交互**
   长按、双击这类没有视觉提示的交互一律删掉。不能用一行文字说明去弥补「用户看不见」。

3. **禁止双重否定开关**
   「关闭 xx 的联网」这种勾选=断网的写法全部改成正向语义（勾=允许）。

4. **入口必须全覆盖**
   设置主页曾漏掉 8 个入口（`lab` / `feed` / `patch` 等），导致功能完全不可达。
   **每次改入口网格，必须和 `SettingsPages.kt` 里登记的子页逐项核对。**

5. **列表行要有摘要**
   图标 + 标题 + **当前状态摘要** + 箭头。用户不点进去就该知道「未设置 / 已断网 / 有 3 项」。

6. **模组图标是正方形**
   圆角 = 0。不要圆形、不要大圆角。

7. **占位数字不能写进代码**
   原型里的假数据（如「已安装 3 个插件」）只用于展示排版。真实实现读不到状态就显示 `—`，**绝不显示假的**。

8. **设置页管默认值，功能页管单次执行**（2026-10-25 定的）
   同一个配置不能两处都能改。迁移页 v1 把设置里已有的东西重做了一遍（迁移模式、扫描启动器、目录库），判为不及格。
   分工：
   - **设置**：工作目录 / 游戏目录 / 手动指定启动器目录 / 默认目标启动器 / 下载并发 / 迁移模式 —— 目录的**增删改**在这里
   - **迁移页**：只从已保存目录里**选**本次用哪两个，选完就执行。页内要写明「改目录去设置 · 存储目录」

## 历史踩坑（避免重犯）

- **inline Composable 内用具名 return 会崩**：`return@Column` / `return@LazyColumn` 在 inline Composable 的 lambda 里会生成两个 end 调用，破坏 SlotTable，报 `length=0; index=-5`（Google issue #2230 / #2225）。已用非 inline 的 `McScope` 包裹或改 if/else。
- **Kotlin 局部函数必须先声明后使用**：已因此编译失败两次。
- **弹窗内容变高后不会自动滚动**：所有弹窗内容区需显式加滚动（`McPickOne` 曾因缺滚动导致「共 40 个」的列表拉不动）。
- **`ci-last-error.txt` 常是旧日志**：真实错误在 `ci/build.log`，别照着过期报错改。
- **两页做同一件事就是重复**：做新页面前，先和已完成的原型逐项对一遍功能清单，重复的删掉，不要各自都做一遍。
- **改完必须确认已推送**：多次出现「本地改完没推上去却报已完成」。推送后要回读仓库验证。

## 怎么用原型

直接用浏览器打开 HTML 即可，无需构建。所有搜索、排序、筛选、页面跳转都是真实生效的，不是静态图。

### 工具箱页（2026-10-26）定下的

9. **九宫格改成列表行**：工具名看不出干什么。17 个工具全部带一行摘要（"找缺少依赖、版本冲突、装错的"）。加搜索框，因为"零散但常用"意味着用户记不住在哪一组。

10. **长文本结果必须独立页面**：体检报告、依赖分析、配置对比、崩溃日志、存储用量 —— 这些正文动辄几百字（崩溃日志 400+ 字），原来塞在 `McLongTextDialog` 弹窗里。结果页统一结构：标题 + 状态徽章 + 等宽正文 + 复制/分享两个按钮。

11. **多选弹窗的确认按钮不能是"说明"**：`modToggle` 的 `confirmText = "说明"` —— 用户勾完模组找不到"完成"，只能点"说明"再关掉，是死路。已改成独立页面：列表 + 全选 + 计数 + 底部「完成」，「怎么生效」另放一个按钮。

12. **多级弹窗链改成单页向导**：导出整合包原来是 格式→内容→嵌入→结果 四连弹。现在一页内选完，底部一个「导出」。

### 更多页（2026-10-26）定下的

13. **长按才能触发的操作必须改成可见按钮**：`more_hint` 文案写的是"**点**「移到底部」"，实际却要长按 —— 文本和实际操作对不上。且移完没法反悔，只能去设置里移回来。现在每行右侧一个可见按钮，移完顶部提示条带「撤销」。

### 服务器页（2026-10-26）定下的

14. **连接、匹配条件必须是独立页面，不能堆在主页长滚动里**：原来主页是一个 Column 从连接卡片一路滚到日志折叠，7 个按钮平铺（`connect` / `probeDirs` / `browseDir` / `scanFiles` / `checkUpdates` / `downloadAll` / 清空）。现在主页只剩三行摘要（连接状态 / 匹配条件 / 扫描目录），详情各自进独立页。

15. **没有 `enabled` 的按钮就是死路**：除「检测更新」外，其余 6 个按钮都没做可用判断，未连接时点了只会失败且不提示原因。现在连接页会算出缺哪几项，写在按钮下方（"还差：面板地址、API Key"）。

16. **手动搜索必须有主动入口**：`Dlg.Manual` 只在 `checkUpdates` 自动匹配失败时被动弹出，用户没法主动改一个已经匹配成功的结果。现在每条文件卡都有「手动搜索」。

17. **破坏性操作不能和主操作并排**：「下载全部可更新」和「清空列表」原来是同一行 `McButtonRow`。现在清空进 `⋮` 菜单，且带确认弹窗，说明不影响服务器上的文件。

18. **日志不能沉在页面最底部**：文件列表一长就永远滚不到。改成 appbar 上的「日志」入口，独立页面 + 复制按钮。

### 整合包页（2026-10-26）定下的

19. **一页里两块语义不同的东西必须分开**：`ModpackFragment` 把「导入的整合包」和「按目录查模组更新」堆在一起，而后者的代码注释自己写着"不属于整合包更新，也不会登记"。现在前者是主页主区，后者收进折叠，并在折叠里写明区别、以及它依赖「迁移前」目录。

20. **弹窗套弹窗改成独立页面**：`showImported` 弹列表 → `showPackActions` 再弹动作列表，两层弹窗。且 `checkPackUpdate` 把可更新清单塞进 `AlertDialog.setMessage`，只 `take(12)` 条，多的永远看不到。改成：列表页 → 详情页（三个动作）→ 更新结果页（可滚）。

21. **多选目标改成独立页面**：`pickTargets` 在弹窗里做多选，之前还要先 `setState("正在扫描可安装的目标…")`。改成独立页面：全选 + 计数 + 底部「安装（N）」，未选时禁用并在上方写明"先勾选至少一个目标"。

22. **"不会真装上"的选项要写明**：服务器页选加载器只是用来筛模组，服务器不会因此安装加载器 —— 文案必须说清楚，否则用户以为点了会给他装 Forge。

23. **进度要可见且防连点**：`checkUpdates` 是三段（算指纹 → 批量反查 → 比对），中途只有一行 `setState` 文本，看着像卡住。现在显示进度条 + 当前步骤，检查期间按钮禁用。

### 整合包页落地时要改的真 bug（读代码发现，原型里已规避）

- `ModpackFragment.onDestroyView` 里有 `handler.removeCallbacksAndMessages(null)`。`Bg.ui` 是全局共享 Handler，清它会把别的页面刚 post 的任务一起清掉 —— 这个坑在设置主页、实验室页、工具箱页都出现过，落地时一并删掉。
- `checkUpdates` 先 `setState("正在算哈希并查询…")` 再判断离线模式，顺序反了：离线时会先闪一句"正在查询"，然后才说"离线模式无法检查"。
