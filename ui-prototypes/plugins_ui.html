插件目录
工作目录 / plugins
每个插件
一个子目录，里面有 manifest.json 和脚本（默认 main.js）
清单字段
id（必填）、name、version、author、desc、engine、entry、permissions
引擎
目前只支持 js
三种权限 net 联网：能发网络请求
files 读写文件：能在插件目录里读和写
prefs 改设置：能读写本应用的设置项

没声明的权限调用时直接报错，不会静默放行。
脚本里能用的
log、toast、http.get、file.read/write/list/delete、prefs.get/set
